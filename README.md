# ESP32 Drone Project

This project demonstrates a low-cost drone surveillance system using ESP32-CAM for real-time video streaming over Wi-Fi.

## Project Overview
The ESP32-CAM module is used to capture live video and transmit it wirelessly to a mobile device or computer through Wi-Fi. The drone can be monitored remotely using a web browser or mobile application.

## Features
- Real-time video streaming
- Wireless monitoring through Wi-Fi
- Low-cost surveillance drone system

## Hardware Components
- ESP32-CAM
- Brushless Motors
- Electronic Speed Controller (ESC)
- Drone Frame
- LiPo Battery
- Mobile Phone (for control)
